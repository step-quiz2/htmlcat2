Hola, CSS!

En acabar aquest capítol sabràs donar color i mida a les teves pàgines amb CSS, escrit en un fitxer a part de l'HTML.

Què és el CSS?

Fins ara, l'HTML deia què és cada cosa: un títol, un paràgraf, una llista… Com es veu (els colors, les mides, les lletres) ho decideix el CSS (de l'anglès Cascading Style Sheets, «fulls d'estil en cascada»). El CSS s'escriu en un fitxer a part, que la pàgina enllaça:

  • El simulador té dues pestanyes: index.html, amb el contingut, i estils.css, amb l'aspecte.
  • <link rel="stylesheet" href="estils.css">, dins del <head>, connecta la pàgina amb el fitxer de CSS: rel diu quina relació hi té (és el seu full d'estil, stylesheet) i href, quin fitxer és. És un element buit.

Prova-ho: a la pestanya estils.css, canvia teal per tomato.

Com s'escriu una regla

El CSS és una llista de regles. Cada regla diu a quins elements s'aplica i què hi canvia:

h1 {
  color: teal;
}
  • h1 és el selector: diu a quins elements s'aplica la regla. Aquí, a tots els <h1> de la pàgina.
  • Entre les claus { i } hi ha les declaracions: què es canvia.
  • Cada declaració és propietat: valor;. La propietat (color) i el valor (teal) van separats per dos punts, i el punt i coma acaba la declaració.

La regla de p s'aplica als dos paràgrafs: un selector amb el nom d'un element tria tots els elements d'aquest tipus.

En aquest exemple curt només hi ha el contingut del <body>, i el simulador hi aplica el CSS sol. En una pàgina sencera, cal el <link>.

Colors i mida de la lletra

  • color és el color del text, i background-color, el color del fons. Amb el selector body, el fons és el de tota la pàgina.
  • Els noms dels colors són en anglès: red, blue, gold, tomato, teal, navy… N'hi ha 140, i vermell no n'és cap. Al capítol 11 veuràs com es pot escriure qualsevol color amb números.
  • font-size és la mida de la lletra, en píxels (px): la mida normal és 16px. El número porta sempre la unitat al darrere, sense espai.

Tria colors que facin que el text es llegeixi bé: fosc sobre clar, o clar sobre fosc.

Comentaris

Al CSS, els comentaris van entre /* i */:

  • El navegador no fa cas del que hi ha dins d'un comentari. Serveixen per explicar el codi… i per «apagar» una declaració una estona.
  • Prova-ho: treu el /* i el */ de la segona declaració, i el fons del títol es tornarà daurat.
  • Al CSS no valen ni els comentaris de l'HTML (<!-- -->) ni els de molts altres llenguatges (//).

Separa el contingut de la presentació

També es pot escriure CSS dins d'una etiqueta, amb l'atribut style:

<p style="color: red">Atenció!</p>

Funciona, però barreja l'aspecte amb el contingut. Amb un fitxer de CSS a part, totes les pàgines del web fan servir el mateix fitxer (canvies un color en un sol lloc i canvia a tot el web), l'HTML queda net i es veu d'un cop d'ull com és cada cosa. Per això el panell ⚠ Problemes avisa quan troba un style. També hi ha l'element <style>, per escriure CSS dins del <head> d'una sola pàgina, però el fitxer a part és millor.

🧹 Codi net: separa el contingut de la presentació

  • L'HTML diu què és cada cosa; el CSS, com es veu. Res d'atributs style.
  • Una declaració per línia, indentada 2 espais; la }, alineada amb el selector.
  • Punt i coma al final de cada declaració, també de l'última.
  • Una línia en blanc entre regla i regla.
  • Comentaris /* */ per explicar les parts del full d'estil.

Errors típics

Aquests exemples tenen errors. Mira el resultat i llegeix el panell ⚠ Problemes (els errors són a la pestanya estils.css).

Falta un punt i coma

No funciona cap de les dues declaracions: sense el ;, el navegador llegeix «navy font-size: 24px» com un sol valor, i no l'entén.

Una propietat mal escrita

El navegador no coneix la propietat colr i no en fa cas, sense dir res.

Un color en català

Els noms dels colors són en anglès: red.

Un número sense unitat

Sense px, el navegador no sap quina mida vols i deixa la que hi havia.

Falta una clau

El títol sí que agafa el color, però la regla de p s'ha perdut: sense la }, el navegador s'ha empassat la regla següent.

Un comentari d'HTML

El títol no agafa el color: el navegador no entén <!--, i el text del comentari s'ha enganxat al selector de la regla.

Sense <link>

El fitxer estils.css és correcte, però la pàgina no el fa servir: li falta el <link> al <head>.

Exercici: dona estil a la recepta

La pàgina de la recepta encara no té estils. Fes que tingui:

  • el fitxer estils.css connectat a la pàgina, amb un <link> al <head>;
  • un color de fons per a tota la pàgina (body);
  • un color per al títol h1, i un altre per als títols h2;
  • una mida de lletra en píxels per als paràgrafs (p);
  • cap error ni cap avís al panell ⚠ Problemes.

Resum

  • El CSS diu com es veu la pàgina. Va en un fitxer a part, que la pàgina enllaça amb <link rel="stylesheet" href="estils.css"> al <head>.
  • Una regla és selector { propietat: valor; }. Un selector amb el nom d'un element (h1, p, body) tria tots els elements d'aquest tipus.
  • color (el text), background-color (el fons) i font-size (la mida, amb unitat: 18px). Els noms dels colors, en anglès.
  • Els comentaris de CSS van entre /* i */.
  • Res d'atributs style: l'HTML per al contingut, el CSS per a la presentació.

Selectors i cascada

En acabar aquest capítol sabràs triar exactament quins elements canvia cada regla, amb classes i selectors combinats, i entendràs quina regla guanya quan n'hi ha diverses.

Classes

Amb el nom d'un element, una regla els canvia tots. Per canviar-ne només uns quants, posa'ls una classe:

  • A l'HTML, l'atribut class posa un nom a uns quants elements: class="avis".
  • Al CSS, el selector .avis (amb un punt davant) tria tots els elements que tenen aquesta classe.
  • Una classe es pot posar a tants elements com vulguis, encara que siguin de tipus diferents.
  • Un element pot tenir diverses classes, separades per espais: class="avis urgent".
  • Els noms de les classes, com els dels id: en minúscules, sense accents i amb guions (menu-principal).

Els paràgrafs amb la classe avis també són p, i la regla de p els vol grisos. Per què guanya el vermell? Ho veuràs a «La cascada».

Ids

Un selector amb # tria l'element que té aquest id:

#horari {
  color: teal;
}

Funciona, però per donar estil és millor fer servir classes: un id només pot ser a un element, i guanya sempre a les classes (també ho veuràs a «La cascada»), cosa que fa difícil canviar els estils més endavant. Els id són per als enllaços a una part de la pàgina (capítol 4) i per a les etiquetes dels formularis (capítol 8). Per això el panell ⚠ Problemes avisa quan un selector fa servir un id.

Selectors combinats

  • h1, h2: selectors agrupats, separats per comes. Les declaracions s'apliquen a tots dos. Escriu cada selector en una línia.
  • nav a: selector descendent. L'espai vol dir «que és dins de»: els a que són dins d'un nav. L'enllaç del paràgraf no canvia, perquè no és dins del nav.
  • p.avis: els p que tenen la classe avis, tot junt, sense espai. Amb espai (p .avis) voldria dir una altra cosa: els elements amb la classe avis que són dins d'un p.

La cascada: quina regla guanya?

Quan diverses regles diuen coses diferents del mateix element, el navegador ho decideix així:

  1. Guanya el selector més específic. Un id és més específic que una classe, i una classe, més que un element.
  2. Si empaten, guanya la regla que ve més avall.

Per això el títol és blau: .titol (una classe) guanya a h1 (un element), encara que la regla taronja vingui després. Prova d'esborrar la regla .titol: llavors empaten les dues regles de h1, i guanya l'última, la taronja.

Per saber quin selector és més específic, compta quants id, quantes classes i quants elements té, i escriu-ho així: (ids, classes, elements).

  • h1 → (0, 0, 1)
  • nav a → (0, 0, 2)
  • .avis → (0, 1, 0)
  • p.avis → (0, 1, 1)
  • #horari → (1, 0, 0)

Es comparen com les paraules al diccionari: primer el nombre d'id; si empaten, el de classes; si encara empaten, el d'elements. Així, .avis (0, 1, 0) guanya a nav a (0, 0, 2).

També existeix !important, que fa guanyar una declaració per sobre de tot. És una trampa que després fa molt difícil canviar els estils: el panell ⚠ Problemes n'avisa.

L'herència

La regla només diu body, però tot el text és blau marí i més gran: alguns estils, com color i font-size, s'hereten, és a dir, passen de cada element als que té a dins (body → p → em). D'altres, com el fons, no s'hereten.

El títol encara és més gran: la mida per defecte d'un h1 és el doble de la del seu pare (aquí, 40 píxels).

🧹 Codi net: noms de classe pel significat

  • Posa a les classes noms que diguin què és l'element: .avis, .preu, .destacat. Res de .vermell, .gran o .centrat: si demà els avisos han de ser blaus, .vermell faria mentir el codi.
  • Per donar estil, classes; els id, per als enllaços i els formularis.
  • Res de !important.
  • Quan agrupes selectors, cadascun en una línia.
  • Noms en minúscules, sense accents i amb guions.

Errors típics

Aquests exemples tenen errors. Mira el resultat i llegeix el panell ⚠ Problemes.

Un punt a l'HTML

El punt només va al CSS. A l'HTML, la classe es diu «.avis», amb el punt inclòs, i el selector .avis no la troba.

Una classe mal escrita

Els noms de les classes han de ser exactament iguals a l'HTML i al CSS: «avís», amb accent, i «avis» són dues classes diferents.

Falta el punt al CSS

Sense el punt, avis vol dir «els elements <avis>», que no existeixen. El selector d'una classe porta un punt davant: .avis.

Classes separades amb comes

El text és vermell (la classe urgent funciona), però no té el fons groc: amb la coma, la primera classe es diu «avis,» i .avis no la troba. Les classes se separen només amb espais.

!important

L'avís hauria de ser vermell, però el !important de la regla de p guanya per sobre de tot, fins i tot de la classe.

Exercici: el tauler d'avisos

Dona estil al tauler d'avisos de l'institut:

  • posa la classe avis als tres avisos, i també la classe urgent al de l'autorització (class="avis urgent");
  • a estils.css, dona un color de fons als avisos (.avis) i un color de text a l'avís urgent (.urgent);
  • dona un color als enllaços del menú, amb el selector nav a;
  • cap error ni cap avís al panell ⚠ Problemes.

Resum

  • Una classe: class="nom" a l'HTML i .nom al CSS. Un element pot tenir diverses classes, separades per espais.
  • #nom tria l'element amb id="nom", però per donar estil és millor fer servir classes.
  • Selectors combinats: h1, h2 (tots dos), nav a (els a de dins d'un nav), p.avis (els p amb la classe avis).
  • La cascada: guanya el selector més específic, comptant (ids, classes, elements); si empaten, el que ve més avall.
  • Alguns estils, com color i font-size, s'hereten: passen als elements de dins.
  • Noms de classe pel significat: .avis, no .vermell.

HTMLCat

Aprèn HTML i CSS al navegador, en català

Un curs per escriure les teves pròpies pàgines web amb codi net i ben estructurat. Sense instal·lar res.

Aprendràs a escriure codi com aquest, i a entendre'l:

<!DOCTYPE html>
<html lang="ca">
  <head>
    <meta charset="UTF-8">
    <title>La meva pàgina</title>
    <link rel="stylesheet" href="estils.css">
  </head>
  <body>
    <!-- Capçalera -->
    <h1>Hola, món!</h1>
    <p class="avis">Aquesta pàgina l'he escrit jo.</p>
  </body>
</html>
/* estils.css */
h1 {
  color: teal;
}

.avis {
  padding: 1rem;
  border-left: 4px solid orange;
}
